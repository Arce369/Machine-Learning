# Predicting Football World Cup Results with Dixon–Coles, MCMC, and XGBoost

This project develops a hybrid statistical and machine learning framework for predicting international football match outcomes, with a specific focus on World Cup simulations. The goal is to combine classical sports analytics models with modern predictive techniques to generate calibrated probabilities, realistic score distributions, and full‑tournament simulations.

The dataset used in this project comes from:  
**[https://github.com/martj42/international_results](https://github.com/martj42/international_results)**  
which provides historical international football match results dating back to 1872.

## Objectives

### 1. Exploratory predictive modeling
Build a complete match‑prediction pipeline capable of estimating both the probability of each possible outcome (home win, draw, away win) and the expected scoreline. The modeling stack includes:

- **Dixon–Coles model:** A classical football analytics model capturing team attack/defense strengths, home advantage, and low‑score correlation.
- **Bayesian MCMC version of Dixon–Coles:** A probabilistic extension that produces full posterior distributions for model parameters, allowing uncertainty quantification.
- **XGBoost Poisson regressors:** Machine learning models designed to capture nonlinear patterns in recent team performance and contextual features.

Together, these models provide complementary perspectives on match dynamics: structural, probabilistic, and data‑driven.

### 2. World Cup simulation
Use the predictive models to simulate complete tournament paths through Monte Carlo methods. This includes:

- Group stage match simulations and standings.
- Knockout bracket progression based on sampled scorelines.
- Probabilities of reaching each round (Round of 16, Quarterfinals, Semifinals, Final).
- Estimated probability of becoming World Cup champion.

The simulation engine relies on the score‑probability matrices generated by each model, enabling realistic tournament behavior and scenario analysis.
